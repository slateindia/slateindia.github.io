# Data dictionary (webapp/data)

Author: Kishan Tiwari. All files are generated by `scripts/build_artifacts.py` from the analysis outputs.

| File | Contents |
|---|---|
| `rainfall/imd_cells.npz` | `rain` (days × 4,964 IMD land cells, mm/day, float32), `dates` (1991-01-01 to 2025-12-31), cell `lat`, `lon`, `row`, `col` |
| `static/imd_cells.csv` | per IMD 0.25° cell: `cell`, centre `lat`/`lon`, `state`, `map_mm` (mean annual precipitation), `rl25_1d`/`rl25_3d` (25-year return levels, mm), `slope_rep` (90th percentile of representative slopes, °), `sand`/`clay` (%), `S`/`S50`/`S75`/`S100` (90th percentile, median, 75th percentile, maximum of the frozen pre-2013 PIBE percentile of its 0.05° cells), `in_domain` |
| `susceptibility/grid.npz` | per 0.05° cell (115,701): `cell_id`, `row`, `col`, `lat`, `lon`, `state`, `susc_class` (PIBE class), `y` (1 = recorded-positive), `src`, `lith_group`, selected predictors, and `score_<model>` for every layer in `layers.json` (NaN where a model has no score) |
| `susceptibility/layers.json` | grid geometry (`west`, `north`, `res` = 0.05, `nrows`, `ncols`, EPSG:4326), class names and area shares (60/20/10/5/5 %), layer list with cross-validation AUC/AP and intervals |
| `susceptibility/shap_global.json` | mean absolute SHAP per predictor, CatBoost member of PIBE |
| `thresholds/params.json` | published I-D parameters; frequentist E-D (α, β, intervals); MaCumBA-type (α, β, G = 1); SACT coefficients, intervals, p*, 5 % budget cut, closed-form exponents with intervals, reference scales |
| `models/<id>.joblib` | fitted nowcast model(s): list of estimators whose predicted probabilities are averaged (three for PI-GBM) |
| `models/<id>.json` | model metadata: predictors (ordered), operating cut, 5 % budget cut, periods, reproduction check, limitations |
| `events/index.json`, `events/<id>.json` | hindcast period, wettest days, per-cell summaries, daily SACT/PI-GBM/frequentist series, mapped landslide points, metrics |
| `validation/*.csv`, `*.json` | the paper's result tables and `numbers.json` |
| `boundaries/states.geojson` | DataMeet state boundaries, simplified (0.01°) |
| `manifest.json` | application, data and model versions, build date |

## Derived daily variables (computed on request, `backend/app/science.py`)

| Variable | Definition |
|---|---|
| `R0`, `R1` | rainfall on the day and the previous day (mm) |
| `A3`…`A60` | rainfall totals over the last n days including the day (mm) |
| `maxR3` | maximum daily rainfall in the last 3 days |
| `E`, `D` | event rainfall to date (mm) and days since event start; wet day ≥ 1 mm; event ends after G = 2 dry days; 0 outside events |
| `E_G1`, `D_G1` | the same with G = 1 (MaCumBA-type definition) |
| `ant15`, `ant30`, `ant60` | rainfall in the n days before the event start (A30 = `ant30`) |
| `FS` | daily TRIGRS factor of safety (30-day response memory, texture-based parameters) |
| `doy_s`, `doy_c` | sine and cosine of day of year |
| `E_rl3`, `R0_rl1` | E / 25-yr 3-day return level; R0 / 25-yr 1-day return level |
